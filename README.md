# Publisher support website

https://cuneyterem8.github.io/ links to the support, privacy and terms for **Istanbul Tea Journey**. English is the default for summaries and future game listings. Turkish remains an explicit language choice.

The static landing page uses local CSS without scripts, trackers, forms or remote fonts. App-specific pages are maintained in `cuneyterem8/support` and served at `/support/`. Other game listings and support pages have been removed at the owner's request; Git history preserves prior revisions.

The existing `app-ads.txt` authorization file remains unchanged; its presence does not add ads to Istanbul Tea Journey, which has no advertising SDK. GitHub Pages publishes `main` at `/`.
