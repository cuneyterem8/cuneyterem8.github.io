# Shared publisher website root

Hosts app-ads.txt at https://cuneyterem8.github.io/app-ads.txt for the Mihriban Erem AdMob publisher account. Game support and policy content remains in cuneyterem8/support at /support/.

The publisher ID is derived from the user-provided real AdMob app/ad-unit IDs. Standard Google direct-seller format: https://support.google.com/admob/answer/9363762 .

## Publisher support landing page

The root page links to the English/Turkish support centers for Istanbul Tea Journey, Blast the Squares, Snake Jack and Pulsar Jack. All UI resources are local CSS; no scripts, trackers, forms, remote fonts or hosted game code are added. App-specific support, privacy and terms remain in the `cuneyterem8/support` repository and are served at `/support/`.

Istanbul Tea Journey has no ads. The existing root `app-ads.txt` is retained unchanged for the other AdMob-enabled game; it is not an advertising integration for Istanbul Tea Journey.
